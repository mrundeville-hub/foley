# foley

Локальное видео → экспериментальный саунд-дизайн → синяя анимированная партитура в терминале.

Стиль звука закреплён четырьмя пользовательскими видео-референсами в `references/SOUND_DIRECTION.md`: выраженная нижняя середина, мягче верх, артикулированные синтетические звуки и короткие разрывы. Их аудио не копируется в результат; синтез и тайминги строятся по входной картинке.

```sh
foley
```

Вставь путь к видео (или перетащи файл из Finder) и нажми Enter. Подойдут также `file:///...` ссылки. По умолчанию всё вычисляется локально, без аккаунта, API и загрузки исходника. Поддерживаются MP4, MOV, M4V, GIF, WebM, MKV и AVI; минимальная длительность — 0,5 секунды. Проект рассчитан на короткие клипы.

Движок `foley_engine.py` собирает звук из контакта, шумового тела, негармонических резонансов и мелких частиц. У каждой сцены свой материал: металл, стекло, резина, гель, керамика, механизм или мембрана. Движение возбуждает тихое трение и короткие жесты с изгибом всего спектра; свет управляет контактами и нарезкой. Старый синтезатор нот и гамм удалён. Короткие отражения объединяют слои, а компрессор и лимитер удерживают пики. Исходное аудио не используется.

Синяя партитура следует визуальному референсу: номера строк, подписи материалов, ступенчатые линии, точки и белые сегменты нарезки. Три блока показывают резонансы, короткие события и нарезку / амплитуду; курсор и подсветка слоёв следуют времени плеера. До генерации экран показывает процедурную анимацию ожидания.

Поле пути и кнопки **New video**, **Process**, **Replay**, **Vary**, **Files** постоянно видны. Чтобы обработать другой ролик, нажми **New video** (или **N**, когда курсор вне поля), вставь / перетащи новый путь и нажми **Enter** или **Process**. Приложение заново анализирует новый файл и сохраняет отдельный результат. При вводе в поле буквенные клавиши работают как обычный текст. Во время генерации поле и кнопки временно заблокированы.

Когда звук готов, автоматически открывается отдельное окно с видео. Плеер `mpv` воспроизводит готовый MP4 с новым звуком: картинка и звук идут по общей временной шкале. CLI получает реальную позицию плеера через локальный IPC, поэтому анимации следуют воспроизведению. Space в CLI или в окне видео ставит на паузу картинку и звук вместе; R в CLI перезапускает просмотр. Закрытие окна останавливает просмотр, Esc в CLI закрывает и плеер. Внутри самого CLI остаются анимации.

Рядом с исходником сохраняются `clip.foley.wav` (стерео, 44,1 кГц, PCM 16 bit) и `clip.foley.mp4` с новым звуком. Оригинальное аудио в выходном видео заменяется. Исходный файл сохраняется. Повторные запуски и вариации получают суффиксы `-2`, `-3` и т. д.

| Клавиша | Действие |
| --- | --- |
| Space | Пауза / продолжить видео и звук вместе |
| R | Смотреть и слушать заново |
| V | Новая вариация с новым seed, используя прежний анализ |
| O | Открыть окно просмотра заново |
| F | Показать результат в Finder |
| N / кнопка New video | Выбрать следующее видео без перезапуска |
| Ctrl+L | Вставить путь к следующему файлу |
| Esc / Ctrl+C | Выйти |

Путь можно передать сразу:

```sh
foley "/Users/me/Movies/clip.mp4"
foley "file:///Users/me/Movies/my%20clip.mp4" --vibe resonant --seed 42
foley "/Users/me/Movies/clip.mp4" --no-ui
```

`--vibe` задаёт характер звука: `formant`, `static`, `pluck`, `flicker`, `resonant`, `haze`, `swarm`, `abyss`. Без флага он выбирается по картинке. `--seed` позволяет повторить звук. `-o /path/result.mp4` задаёт точное имя первого успешно обработанного результата и заменяет существующий файл с этим именем; рядом записывается WAV. Следующие ролики и вариации получают новые имена рядом со своим исходником. Эти флаги работают и в интерактивном режиме.

Дополнительно можно подключить установленный и авторизованный CLI для смыслового анализа кадров:

```sh
foley clip.mp4 --agent codex
foley clip.mp4 --agent claude --model sonnet
foley clip.mp4 --agent gemini
foley clip.mp4 --agent auto
```

Агент получает контактные листы и события, а звук по-прежнему синтезируется локально. Если агент недоступен, используется анализ движения и света.

Для установки нужны Python 3.10+, FFmpeg и mpv (для окна синхронного просмотра):

```sh
brew install ffmpeg mpv
uv tool install --editable .
```

На этом компьютере команда `foley` уже подключена к исходникам проекта. Для анимаций рекомендуется терминал от 80×24 символов с поддержкой цвета. Приложение уважает `NO_COLOR`, если эта переменная задана.

Проверки:

```sh
python test_foley.py
python -m unittest test_engine test_workflow -v
```

`test_foley.py` проверяет детектирование событий и все звуковые палитры. `test_workflow.py` проверяет путь с пробелами / file URL, CLI-рендер, сохранение предыдущих результатов, работу интерфейса и реальное управление часами/паузой mpv через IPC. UI-тест использует управляемый плеер-заглушку, IPC-тест запускает mpv без экрана и звука.

`test_engine.py` проверяет повторяемость seed, различие материалов, независимость от музыкальной тональности, начало контакта, затухание, тишину и пределы мастер-шины. Эти проверки не заменяют прослушивание. Четыре актуальных примера с одинаковым seed 42: `qa/material-engine/ref_01_material.mp4` … `ref_04_material.mp4`. Запустить повторный рендер: `python qa/render_material_engine.py` (нужны исходные локальные референсы и сохранённая предыдущая версия).
